# Haven Mobile

Haven Client for Android: Minecraft Java Edition on your phone, with the Haven account, the Haven mod and Haven Play.

- **Haven Play:** paste the invite code a friend shares from Haven Client desktop (Multiplayer tab). The friend's version, loader and mods install by themselves and the game joins their world. Works over the direct address or the Cloudflare tunnel, no extra app needed.
- **Haven account:** sign in with Google (same account and in-game name as on the PC) or with Microsoft.
- **Haven mod:** capes, titles and the Haven menu load into every Fabric profile of a supported version (1.21.1 – 26.3).
- **FPS pack:** the first start of a Fabric profile adds Sodium, Lithium, FerriteCore, ImmediatelyFast, Entity Culling and ModernFix for that exact version (Settings can turn it off). Render resolution starts at 80%.

Download: <https://havenclient.net/client/> or the [releases](https://github.com/AjanKopke/haven-mobile/releases).
